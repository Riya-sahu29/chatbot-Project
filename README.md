# 🤖 AI Chatbot Project (FastAPI + React)

An AI-powered chatbot built with **FastAPI (Python)** for the backend and **React + Vite + TailwindCSS** for the frontend.  
It uses **LangChain** and **Groq API** to generate intelligent responses.

---
## 📁 Project Structure

✨ Features

AI chatbot using LangChain

Groq API integration

FastAPI backend

React + TailwindCSS frontend

Postman API testing

Secure environment variables

Scalable architecture

---

## 🚀 Backend Technologies (Python)

Installed using `pip`:

- fastapi  
- uvicorn  
- langchain  
- groq  
- python-dotenv  
- requests  
- pydantic  
- sqlalchemy

## 🎨 Frontend Technologies
